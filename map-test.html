Troubleshooting Steps:

  1. Check browser console (F12) for error messages
  2. API Key Issues: Verify key is correct and not restricted
  3. Enable API: "Maps JavaScript API" must be enabled in Google Cloud Console
  4. Billing: Google requires billing enabled (free tier available)
  5. Domain restrictions: Check if API key is restricted to specific domains
  6. Try incognito mode: Rules out browser cache issues

Common Error Messages:

  • "This API project is not authorized" = Billing not enabled
  • "API key not valid" = Wrong key or restrictions
  • "RefererNotAllowedMapError" = Domain restrictions
  • Nothing loads = Network/firewall blocking
